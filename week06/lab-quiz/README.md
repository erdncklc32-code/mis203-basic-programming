# Python Kulüp Öğrenci Kayıt Sistemi

## Proje Hakkında
Bu proje, bir öğrenci kulübünün kayıt işlemlerini yönetmek amacıyla Python kullanılarak hazırlanmıştır.

Kulübün sunduğu üç ana branş:
- Yazılım
- Tasarım
- Pazarlama

## Kullanılan Python Konuları
- **Tuple:** Değiştirilemeyen branş listesini oluşturmak için kullanılmıştır.
- **List:** Öğrenci kayıtlarını saklamak için kullanılmıştır.
- **append():** Listeye yeni öğrenci eklemek için kullanılmıştır.
- **insert():** Başkan öğrencisini listenin başına eklemek için kullanılmıştır.
- **strip():** Öğrenci isimlerinin başındaki ve sonundaki boşlukları temizlemek için kullanılmıştır.
- **len():** Toplam öğrenci sayısını hesaplamak için kullanılmıştır.
- **remove():** Kulüpten ayrılan öğrenciyi silmek için kullanılmıştır.
- **pop():** Son kaydedilen öğrenciyi listeden çıkarmak için kullanılmıştır.
- **sorted():** Listenin geçici alfabetik sıralamasını oluşturmak için kullanılmıştır.
- **sort():** Ana listeyi kalıcı olarak alfabetik sıralamak için kullanılmıştır.


## Amaç
Python'da temel veri yapılarını ve liste metotlarını uygulamalı olarak öğrenmek ve kullanmak.
